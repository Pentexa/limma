IMPORTANT

Docker Sandbox Entegrasyon Yöntemi (Phase 2): Docker sandbox için Rust tarafında shiplift veya bollard kütüphanelerinden biri kullanılacaktır. Daha aktif güncellenen ve asenkron (Tokio) desteği mükemmel olan bollard kütüphanesini kullanmayı öneriyoruz. Ayrıca Windows ortamında Docker Desktop'ın kurulu olması ve Named Pipe (\.\pipe\docker_engine) erişiminin aktif olması gerekmektedir.

DOM XSS Headless Browser Seçimi (Phase 4): DOM XSS tespiti için headless bir tarayıcıya ihtiyaç vardır. Rust ekosisteminde headless_chrome kütüphanesini entegre etmeyi planlıyoruz. Bu kütüphane Chromium tarayıcısını otomatik indirip yönetebilmektedir. Alternatif olarak Playwright/Puppeteer içeren ayrı bir Node.js mikroservisi veya CLI aracı da kurulabilir. Önerimiz, sistem karmaşıklığını azaltmak için doğrudan Rust içindeki headless_chrome kütüphanesini kullanmaktır.

OOB (Out-Of-Band) Sunucu Altyapısı (Phase 4): Blind SSRF ve Blind XXE gibi açıklar için OOB Callback sunucusuna ihtiyaç vardır. Plan kapsamında yerel bir DNS/HTTP Callback sunucusu prototipi kurulacaktır. Ancak kurumsal seviyede kullanım için Burp Collaborator Client API veya Nuclei-interactsh entegrasyonu da plana dahil edilmiştir.

Dağıtık Hız Sınırlayıcı (Phase 5): Distributed Rate Limiter için Redis bağımlılığı eklenecektir. Eğer Redis kullanılmayacaksa, in-memory sliding-window algoritması ile devam edilecektir.
